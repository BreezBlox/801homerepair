# Contractor Context

## Business snapshot

This context pack is for a local contractor / handyman operation serving Salt Lake County, Utah.

The operating style is:
- practical
- budget-conscious
- direct
- detail-aware
- focused on real job execution, not glossy contractor theater

The work tends to sit in the zone between handyman and light contractor services rather than large GC-style projects.

## Typical job types

Common examples from prior context include:
- flooring installs and flooring prep
- carpet removal and disposal coordination
- baseboard / moulding / trim work
- fence and post repairs
- sign post resets
- digging-related repair work
- small exterior repair jobs
- general residential punch-list and service work

## Operating preferences

- Solutions should be realistic for a small operator or small crew.
- Recommendations should respect budget, tool availability, transport constraints, and local sourcing friction.
- Outputs should be useful in the field, not just theoretically correct on a laptop.

## Decision style

Default decision order:
1. safety and avoidable risk
2. feasibility with tools, transport, and labor available
3. durability appropriate to the job
4. cost control
5. speed / convenience

## Communication style

Customer-facing communication should:
- sound straightforward and competent
- avoid jargon unless needed
- explain what is included in labor when that helps justify price
- avoid over-explaining tiny internal details
- clearly separate what is included vs what still needs confirmation

Internal planning should:
- identify hidden scope risks early
- call out likely failure points
- distinguish known facts from assumptions

## Source-of-truth rules

Use repo docs in this order for contractor work:
1. latest user instruction
2. repo-level documented rules
3. current uploaded estimate sheets or project files
4. older remembered context

Do not merge conflicting pricing sources silently.

## Example project memory worth preserving

A standing remembered rule from prior contractor work:
- before finalizing any estimate, run a pre-job tool/logistics audit covering tool ownership, on-site power, specialty attachments, digging tools vs hole sizes, and material transport constraints

Another standing rule:
- when materials are customer pickup, verify and confirm the exact store location and real-time availability before sending the customer to pick them up

These are process rules, not optional nice-to-haves.
