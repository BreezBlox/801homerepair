## Practical installation workflow recovered from context

1. Mark turf boundaries, concrete edges, house line, and obstacles.
2. Call 811 before digging.
3. Remove existing grass, roots, and unsuitable organic material.
4. Excavate to needed depth, likely around 3–4 inches where full build-up is required.
5. Rough-grade subgrade and preserve a slight slope away from the house.
6. Install weed barrier only if the chosen method/product calls for it.
7. Install compactable base in **1–2 inch lifts**.
8. Compact each lift thoroughly.
9. Fine-grade the top of base to correct finish height against hardscape and foundation edges.
10. Roll out turf and dry-fit to minimize seams.
11. Cut carefully from the backing side around edges and obstacles.
12. Seam only if necessary and keep pile direction consistent.
13. Secure edges using the appropriate method for the condition and edge type.
14. Add infill if required by the turf product.
15. Groom, trim, clean up, and do final walkthrough.

## Known site risks

- Improper drainage toward the house/foundation
- Finish height problems at sidewalk/concrete transitions
- Soft subgrade or organic soil left in place
- Underestimating labor because the layout is narrow and detail-heavy
- Messy seams or poor pile-direction matching
- Difficult fitting around penetrations/obstacles
