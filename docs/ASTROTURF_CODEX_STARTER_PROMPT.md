# Codex Starter Prompt

Use the files in this workspace to help me work on an astroturf job for my handyman/contractor business.

Read:
- `AGENTS.md`
- `docs/ASTROTURF_JOB_CONTEXT.md`
- `docs/ASTROTURF_SCOPE_DRAFT.md`
- `docs/ASTROTURF_MISSING_INFO.md`

Rules:
- Do not invent measurements or pricing inputs.
- Keep a hard distinction between what is known, inferred, and missing.
- Prefer practical contractor language over corporate fluff.
- If I ask for an estimate, either build a conditional estimate or tell me exactly what inputs are still needed.
- Keep drainage, base prep, finish height, and detail-heavy labor risk front and center.

When helping, default to outputs like:
- estimate draft
- scope of work
- materials checklist
- site inspection checklist
- customer text/email
- job notes / work plan
