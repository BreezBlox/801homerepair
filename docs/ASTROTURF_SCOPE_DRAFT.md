# Astroturf Scope Draft

This is a **working draft scope**, not a final signed scope. It is based only on recovered context.

## Draft scope of work

Provide labor and planning for installation of artificial turf in narrow side-yard/landscape-strip areas adjacent to the house and sidewalk/concrete edges.

### Likely included tasks

- Confirm work boundaries and layout
- Protect adjacent surfaces as needed
- Remove existing grass/root material and unsuitable top material in turf areas
- Perform shallow excavation as needed for proper build-up and finish height
- Rough-grade subgrade for drainage away from the house/foundation
- Supply and install compactable base material if included in final pricing
- Compact base in lifts and fine-grade for finished surface
- Dry-fit, trim, and install artificial turf
- Cut around edges, corners, and site obstacles
- Complete seams only where necessary
- Secure perimeter edges with the selected edge method
- Install infill if required by selected turf product
- Final trim, grooming, cleanup, and walkthrough

## Working exclusions

Unless specifically added later, exclude:

- irrigation modification or repair
- major drainage correction beyond minor grading for turf prep
- concrete, curb, or hardscape modification
- utility relocation
- repair of unrelated landscape structures
- permit fees
- haul-off beyond the agreed disposal plan
- unforeseen subsurface correction beyond normal prep

## Pricing posture for Codex

If asked to draft an estimate from this file alone:

- Do not output a single confident lump-sum price as if measurements are known.
- Either produce a conditional estimate with assumptions, or generate a missing-info request first.
- Emphasize that narrow, detail-heavy areas often price worse per square foot than open rectangular turf installs.
