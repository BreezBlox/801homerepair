# Contractor repo instructions

Read these first before doing contractor-related work in this repo:

1. `docs/CONTRACTOR_CONTEXT.md`
2. `docs/ESTIMATING_RULES.md`
3. `docs/LOGISTICS_RULES.md`

For astroturf-specific work, also read:

4. `docs/ASTROTURF_JOB_CONTEXT.md`
5. `docs/ASTROTURF_SCOPE_DRAFT.md`
6. `docs/ASTROTURF_MISSING_INFO.md`

These docs override vague memory, older chat fragments, and generic handyman assumptions.

## Purpose of this repo

This repo supports a practical local contractor / handyman operation serving Salt Lake County, Utah.
Typical work includes flooring installs, trim/baseboard work, repairs, fence/post resets, small exterior jobs, and other hands-on residential tasks.

## Non-negotiables

- Do not invent measurements, quantities, product specs, local code requirements, or stock status.
- Do not bury uncertainty. Surface it.
- Do not collapse conflicting pricing references into one fake-clean number.
- When a pricing conflict exists, explicitly note it and use the most current documented sheet or the user's latest instruction.

## Estimating behavior

When asked to draft an estimate:
- use `docs/ESTIMATING_RULES.md`
- distinguish labor, prep, fees, materials, assumptions, and exclusions
- present labor in a way that feels justified and professional, not like random magic numbers
- keep customer-facing estimates readable
- note whether materials are customer pickup, contractor pickup, or still undecided

When asked to help with a flooring estimate:
- use the uploaded estimate-sheet rates captured in `docs/ESTIMATING_RULES.md` unless the user overrides them
- preserve flooring-specific rates separately from broader handyman pricing

## Logistics behavior

When asked to plan or prep a job:
- use `docs/LOGISTICS_RULES.md`
- run the pre-job tool/logistics audit before finalizing recommendations
- for customer pickup, verify exact store and real-time stock before suggesting pickup
- for digging work, flag utility-locate risk before presenting the job as routine

## Astroturf behavior

For astroturf job work recovered from prior context:
- treat the astroturf docs as provisional but usable
- preserve the distinction between confirmed, inferred, and missing
- do not fabricate square footage, turf brand, pile height, disposal method, irrigation conditions, or customer budget
- if asked for pricing with incomplete information, either produce a missing-info checklist or a conditional estimate with assumptions labeled
- keep drainage, finish height near concrete/foundation, soft subgrade, seam placement, and detail-heavy labor risk front and center
- assume 811 should be called before digging
- keep customer-facing wording plain and contractor-appropriate

## File preferences

- Put reusable pricing, SOPs, and checklists in `docs/`
- Keep customer-facing templates concise and easy to edit
- Prefer markdown unless another format is specifically needed
